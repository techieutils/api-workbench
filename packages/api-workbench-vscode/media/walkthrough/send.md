# Edit and send a request

Click a request to open it in the **request editor**. Change its method, URL, params, headers, or body, then **Save** (<kbd>⌘ S</kbd> / <kbd>Ctrl S</kbd>). **Send** (<kbd>⌘ Enter</kbd> / <kbd>Ctrl Enter</kbd>) saves your changes first.

The response appears beside it, with its body, headers, cookies, tests, and timeline. Every send also appears in the **API Workbench** panel's **Network** tab.
