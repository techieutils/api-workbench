# Your API workspaces

The **API Workbench** sidebar lists two kinds of workspace:

- **Team folders** in this repository: any folder with an API Workbench `workspace.json` and `collections/`.
- **The app's workspaces**, when the API Workbench app is installed on this computer.

Each has its collections, environments, API specs, mock servers, and — for the app's — history, saved credentials, and cookies. Nothing here sends a request until you ask.
