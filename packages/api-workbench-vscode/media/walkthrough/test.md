# Test, mock, and ask Copilot

- **Run Tests** on a request, folder, or collection reports to the **Testing** view.
- **Run Collection in Runner…** runs a collection several times, over a data file, or as a load test.
- **Start mock** above an OpenAPI file serves a mock server answering for each operation.
- In Copilot's agent mode, ask about your APIs: `#apiRequests`, `#sendApiRequest`, `#runApiTests`, and `#checkOpenApi` list, send, test, and check them. You confirm every send and run, and request scripts do not run unless you allowed them for good in **apiWorkbench.scripts**.
