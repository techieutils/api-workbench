# Guides

Each guide walks through a complete task from start to finish. They assume API Workbench is [installed](../installation.md) and you know your way around the [interface](../interface.md).

```cards
- title: Test a REST API end to end
  icon: check-decagram-outline
  href: test-a-rest-api.md
  text: Build a collection with environments and tests, then run it.
- title: Chain requests with captured variables
  icon: link-variant
  href: chain-requests.md
  text: Sign in once, capture the token, and reuse it in every request.
- title: Load test an API
  icon: speedometer
  href: load-test-an-api.md
  text: Benchmark endpoints and run performance tests with thresholds and baselines.
- title: Run API tests in CI
  icon: source-branch-check
  href: run-api-tests-in-ci.md
  text: Test a team workspace on every push, with results in your CI system.
- title: Capture and replay app traffic
  icon: radar
  href: capture-app-traffic.md
  text: Record what a browser or mobile app sends, then replay and edit it.
- title: Connect to an OAuth 2.0 API
  icon: key-variant
  href: oauth-with-discovery.md
  text: Discover the endpoints, sign in, and keep tokens in the vault.
```
